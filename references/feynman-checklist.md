# 费曼门禁清单 Feynman Gate Checklist

每个单元生成视频前，必须逐项打勾。任一项不通过，回第 5 步重讲。

## 观众检查

- [ ] MISSION.md 写清了给谁看、看完能讲出什么、发在哪个平台。
- [ ] 观众起点已确认：本期只往前推一步；往期讲透、已收入 GLOSSARY.md 的词可直接用，其余术语当场解释。

## 讲稿检查

- [ ] 本单元只有一个核心概念，顶部一句话能说清。
- [ ] 全篇不用术语；必须用的术语第一次出现就用人话解释（GLOSSARY.md 里已收录的除外）。
- [ ] 每句话目标观众能听懂（默认 12 岁孩子；自测：换成给邻居家小孩讲，会卡吗？）。
- [ ] 结构完整：这是什么 → 为什么需要 → 怎么工作（类比 + 例子）→ 易错在哪 → 一句话总结。
- [ ] 至少 1 个生活类比 + 1 个具体例子，不是抽象定义堆砌。
- [ ] 没有“其实就是 / 本质上 / 众所周知 / 显而易见”这类掩盖卡点的词。
- [ ] 没有连续 3 句无例子的抽象论述；没有超 40 字的长句未拆分。

## 模拟观众追问

- [ ] 已用目标观众视角提出至少 3 个最难的追问（为什么 / 那如果……呢 / 能举个例子吗），写在 GAP-LOG.md。
- [ ] 每个追问在讲稿里都有答案，或明确判断为本期不讲、留给下一期。

## 卡点检查

- [ ] GAP-LOG.md 已记录全部卡点：原句 / 卡在哪里 / 回去查了什么。
- [ ] 每个卡点都已回源补漏，补漏来源在 RESOURCES.md 可查。
- [ ] 重讲后卡点消失，能一口气讲通。

## 视频一致性检查

- [ ] 旁白与 FEYNMAN.md 逐字一致。
- [ ] 时长与字数匹配决策表（1 分钟 200-240 字 / 3 分钟 600-720 字 / 5 分钟 1000-1200 字）。
- [ ] 画面只解释讲稿，不新增知识点；图上无未解释术语。
- [ ] 每 30 秒至少一次例子或画面变化。
- [ ] 字幕与旁白一致。

## 事实检查

- [ ] 讲稿与视频里的每个事实断言，在 RESOURCES.md 有来源标注。
- [ ] 查不到的标注“未找到”，没有编造。
