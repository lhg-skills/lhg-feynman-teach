# 冒烟测试 Smoke Test

用一个最小主题跑通一次完整流程，验证 skill 可用。

## 测试主题

用“什么是复利”做测试（概念单一、类比明确、易验证）。

## 步骤

1. 输入 `/feynman-teach 复利`，确认输出 MISSION.md（为什么学、成功标准）。
2. 确认 RESOURCES.md 有至少 2 个可信来源且带标注，不是裸链接。
3. 确认 FEYNMAN.md 通过费曼门禁清单（术语都解释、有类比+例子、无掩盖词）。
4. 确认 GAP-LOG.md 有至少 1 条卡点记录（例如“复利与单利的区别讲不清”→回源补漏）。
5. 确认视频时长选择有理由（复利应选 1 分钟或 3 分钟，并说明为什么）。
6. 确认 video/ 有 script + storyboard + subtitles，旁白与 FEYNMAN.md 一致。
7. 确认 quiz.md 有 3 道“为什么/举例子”题，review-plan.md 有当天→2天→7天→30天计划。

## 通过标准

7 项全通过 = 冒烟通过。任一项失败，记录失败项 + 修改方案，回到 SKILL.md 对应章节修复。
