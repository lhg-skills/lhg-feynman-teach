# 视频生成规范 Video Spec

## 基本原则

- 旁白 = 通过费曼门禁的讲稿，逐字用，不重写。
- 画面只解释讲稿，不新增知识点。
- 时长由复杂度决定，不凑时长、不砍关键步骤。

## 时长决策（与 SKILL.md 一致，此处给执行细节）

### 1 分钟版：单一概念快讲

- 适用：1 个概念 + 1 个类比 + 1 个例子。
- 旁白约 200-240 字中文，语速约 220 字/分钟，留 3 秒钩子 + 5 秒结尾停顿。
- 结构：0-3 秒钩子（一个反常识提问或痛点）→ 3-35 秒核心（这是什么 + 为什么需要）→ 35-53 秒例子 → 53-60 秒一句话总结 + 下一步。
- 画面：横屏 16:9，1920×1080（竖屏由用户自己拼，见文末）；1 张主图 + 1 个演示镜头；字幕全程烧录，关键术语高亮。
- 发布：短视频 / 视频号 / 朋友圈；标题取讲稿的一句话总结。

### 3 分钟版：默认标准课

- 适用：1 个完整小课，2-3 个步骤 + 1 个易错点。
- 旁白约 600-720 字，语速约 220 字/分钟。
- 结构：0-15 秒钩子 + 为什么学 → 15-105 秒核心（类比 + 例子，分 2-3 步）→ 105-150 秒卡点/易错（“最容易错的是……”）→ 150-180 秒复盘 + 下一步。
- 画面：横屏 16:9（竖屏由用户自己拼）；3-5 个镜头，每 30 秒至少一次画面变化（换图 / 演示 / 板书）。
- 字幕：SRT + 烧录字幕二选一，默认输出 SRT，平台要求时烧录。

### 5 分钟版：系统 / 链条深讲

- 适用：多概念有依赖、需要完整推导或完整演示。
- 旁白约 1000-1200 字。
- 结构：0-20 秒钩子 → 20-200 秒分步推导（每步配例子，每步有小标题卡）→ 200-260 秒易错 + 对比（A vs B 表格/对比图）→ 260-300 秒总结 + 作业（一个最小可做任务）。
- 画面：横屏 16:9，分 3-4 节，每节开头有小标题卡；关键推导用步骤图，不用长文字屏。
- 拆分规则：写完讲稿发现超过 1200 字，先拆集，不硬塞进 5 分钟。

### 超过 5 分钟

- 不直接做。拆成多集 3 分钟，或 1 集 5 分钟 + 1 集 1 分钟精华版。
- 每集独立有钩子与总结，可单独看。

## 视觉模式（二选一，默认幻灯片）

- **幻灯片模式（默认）**：快、稳、够用。按下面 6 步管线做。
- **手绘模式（可选）**：过程 / 机制 / 因果链、需要边画边讲时选。管线见 `references/handdraw-mode.md`：声音先行 → 分镜到句 → 绘制计划 → 先轮廓后填色 → 按部位描线 → 手与笔（可选）→ 字幕唯一性 → 代表段检查 → 质检交付。无手绘合成能力时，输出手绘待制作包，不谎称已生成手绘成片。

## 制作管线（6 步，幻灯片模式）

1. **讲稿定稿**：FEYNMAN.md 通过门禁，锁定版本。
2. **分镜**：按句切镜头，`storyboard.md` 每行：序号 / 旁白句 / 画面描述 / 时长 / 字幕 / 转场。
3. **视觉**：图示、演示、板书三选一；图上文字不超过 12 字；不出现讲稿没讲过的术语。
4. **配音**：用讲稿生成旁白；语速按时长倒推；无 TTS 工具时，输出带停顿标记（`[停顿]` / `[重读]`）的旁白文本。
5. **组装**：画面 + 旁白 + 字幕合成；优先用环境自带能力（ffmpeg / 平台视频生成）；无能力时输出待剪辑包（script + storyboard + 旁白 + 画面描述 + 素材清单）。
6. **质检**：跑 `scripts/check_delivery.py`（见 SKILL.md“完成判定”），再看抽帧回答：12 岁能听懂吗？每 30 秒有例子或画面变化吗？有术语没解释吗？任一不通过，回费曼循环改讲稿。

## 输出文件（`video/` 目录）

- `script.md`：旁白全文（= FEYNMAN.md 讲稿）
- `storyboard.md`：分镜表
- `video.mp4`：成片；无合成工具时为 `TODO-待剪辑.md` + 说明，不谎称已生成
- `subtitles.srt`：字幕
- `cover.md`：封面文案（标题 + 副标题 + 封面图描述）
- `vertical-copy.md`：竖屏拼版文案（见下）

## 竖屏拼版文案（用户自己拼竖屏时用）

- 成片只交付横屏 16:9，不直接出拼好的 9:16。用户拿到 16:9 后自己拼竖屏：16:9 原样居中，上下留边加东西。
- 每次交付同时给 `vertical-copy.md`，包含：
  - 上部标题：2 行，吸睛 + 总结性，第 1 行钩子，第 2 行一句话结论。
  - 下部信息：1 行，日期 + 出品人（例如“刘洪光实名上网 · 2026-10-15”），日期按交付日填，不编造。
- 16:9 画面主体居中、不贴边，留出拼竖屏时的视觉余量。成片内不重复加竖屏上下标题，避免和用户后期拼的标题撞车。

## 常见坑

- 旁白与讲稿不一致：改视频前先改讲稿，重过费曼门禁。
- 为凑时长加废话：宁可做 1 分钟精华版，不做 3 分钟水课。
- 画面堆文字：画面是讲稿的图解，不是讲稿的复读机。
- 无字幕：短视频默认烧录字幕，长视频至少给 SRT。
