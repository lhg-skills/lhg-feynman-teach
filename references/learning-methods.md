# 其他学习法分析：为什么选费曼做核心，其他方法怎么叠加

本文件回答用户的问题：“不光费曼，如果还有别的学习法，帮我分析一下。”

结论先说：**费曼做核心（讲通检验）+ 检索 + 间隔 + 双重编码做支撑 + 布鲁姆做目标分层 + 刻意练习做技能打磨**，是本 skill 的叠加方案。其他方法不是不用，而是各就其位，不抢核心。

## 对比表

| 学习法 | 核心做法 | 优点 | 短板 | 在本 skill 里的位置 |
|---|---|---|---|---|
| **费曼学习法**（Feynman Technique） | 选概念 → 用大白话讲给外行 → 找卡点 → 回源补漏、简化重讲 | 直接暴露“假懂”；讲通 = 真懂；讲稿可直接转视频 | 对纯技能（肌肉记忆、操作手感）覆盖弱；需要有人/自己当听众 | **核心门禁**：每个单元必过费曼四步 |
| **检索练习**（Retrieval Practice，Roediger & Karpicke 的测试效应） | 不看答案，先凭记忆回忆、默写、答题 | 长期留存最强证据之一；区分流利错觉与真记忆 | 需要题库与反馈；只做选择题容易变成认选项 | **支撑**：每单元 3-5 道“为什么/举例子”自测 + 复习时先默讲 |
| **间隔重复**（Spaced Repetition，艾宾浩斯遗忘曲线） | 同一内容在拉长的时间间隔后重复 | 对抗遗忘，投入产出比高 | 间隔需要计划与坚持；不适合一次性学完就用的场景 | **支撑**：复习计划 当天→2天→7天→30天 |
| **双重编码**（Dual Coding，Paivio） | 文字 + 图像同时呈现（图示、演示、板书） | 图文互补，降低工作记忆负担；视频天然适合 | 图文不一致反而添乱；图多会喧宾夺主 | **支撑**：视频画面必须与讲稿一一对应，不新增知识点 |
| **交错练习**（Interleaving，Rohrer） | 把相关但易混的主题混着练 | 提升辨别力，防“练会了 A 就以为会了 B” | 初学阶段交错会增加负担；需要先单点过关 | **支撑**：单元都过费曼门禁后，用对比题做交错复习 |
| **精细加工 / 追问为什么**（Elaboration） | 不断问“为什么会这样？如果换个条件呢？” | 把孤立知识点连成网络 | 容易追问发散、偏离使命 | **支撑**：费曼第 3 步找卡点时用“为什么”追问；但以使命为边界 |
| **布鲁姆分类**（Bloom，1956） | 按记忆→理解→应用→分析→评价→创造分层定目标 | 目标分层清晰，防“只停留在记忆层” | 本身不教怎么学，只是目标框架 | **目标分层**：MISSION 里写清本单元要到哪一层（理解 / 应用 / 创造） |
| **刻意练习**（Deliberate Practice，Ericsson） | 在最近发展区内、带即时反馈、重复练弱项 | 技能类（编程、乐器、演讲）进步最快 | 需要反馈回路与教练/评测；纯概念学习用不上 | **技能打磨**：技能型单元用刻意练习；概念型单元用费曼 |
| **康奈尔笔记 / SQ3R / PQ4R** | 结构化阅读与笔记（提问→阅读→复述→复习） | 输入阶段有章法，适合啃书/啃文档 | 停留在输入端，不检验输出 | **输入阶段**：读 RESOURCES 时用；读完必须进费曼输出，否则不算学完 |
| **第一性原理** | 回到最基本的事实与假设再推导 | 防人云亦云，适合决策与系统设计 | 对有标准答案的基础概念是过度杀伤 | **可选**：系统/决策类主题在费曼第 4 步用；基础概念不用 |
| **苏格拉底提问 / 教学相长** | 用连续提问逼出假设与矛盾 | 适合辨析、纠偏 | 需要对话者；单人自学容易自问自答走过场 | **可选**：有真实听众（团队/评论区）时用；视频评论区的问题可回流为卡点 |
| **项目制 / 做中学**（Learning by Doing） | 直接做一个真实项目，在做中学 | 迁移最强，学完即用 | 耗时长；无脚手架时容易卡在无关细节 | **可选**：使命是“能做出东西”时，视频作业 = 一个最小可交付项目 |

## 为什么不选其他方法做核心

- 检索 + 间隔很强，但它们检验的是“记得住”，不检验“讲得清”。能背下来不等于能讲给别人听，费曼补的正是这一层。
- 双重编码很适合视频，但它解决的是“呈现”，不解决“理解”。画面再漂亮，讲稿本身没讲通，视频只是精致的假懂。
- 布鲁姆、刻意练习是目标与训练框架，不是“是否真懂”的检验器。它们需要费曼先把“懂”定义清楚。

所以分工是：**费曼定“懂的标准”，检索+间隔管“记得久”，双重编码管“看得懂”，布鲁姆管“学到哪层”，刻意练习管“练得熟”。**

## 叠加后的学习效率为什么更高

1. **一次产出，三重收益**：同一份费曼讲稿，同时是学习结论、自测底稿、视频旁白，不做三遍重复活。
2. **卡点前置**：费曼在学的时候就把不懂的地方挖出来，而不是考试/上台时才暴露。
3. **视频是公开承诺**：要拍出来给人看，倒逼讲稿必须通俗、完整、无跳步，比只写给自己看的笔记要求更高。
4. **间隔复习有抓手**：复习时不是重看视频，而是先默讲费曼讲稿，讲不出来再看，检索效应拉满。

## 什么主题不适合纯费曼

- 纯操作手感（乐器、球类、手术操作）：费曼讲通只是起点，必须配刻意练习 + 真实反馈。
- 需要大量记忆的清单（药名、法条）：费曼可讲清原理，但记忆仍需间隔重复 + 口诀/联想。
- 高度依赖直觉的审美（设计、品味）：费曼能讲清原则，但品味需要大量案例对比 + 专家反馈。

遇到这三类，本 skill 会在 MISSION 里标注，并自动把刻意练习 / 间隔重复的权重调高。
